# News in One Image — 18 November 2026

One image summing up the world's news of Wednesday 18 November 2026,
built for make.fun's "Sum up 18 November's world news in one image"
bounty ($250 in USDC).

The image is a newspaper-style front page: the tanker war in the Gulf
(the US said it sank five Iranian oil tankers overnight; Iran hit back
at ships near Hormuz, with missiles at the Al-Azraq base in Jordan and
a drone strike on a US radar facility in Bahrain), the Kerch Bridge hit
for the second night in a row, the COP31 climate talks in Antalya
entering their decisive phase, and the Quad leaders meeting in Manila.

## Run

The program writes the image deterministically, with no network:

```
python3 main.py
```

It copies the bundled image to `/output/entry.png` — running it twice
writes the same bytes. The image is a 1024x1024 PNG under 1 MiB.
